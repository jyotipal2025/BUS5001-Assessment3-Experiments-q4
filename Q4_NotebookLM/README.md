# Q4 – NotebookLM Evaluation

This folder contains experiment logs and evidence for Question 4 of BUS5001 Assessment 3.

The evaluation used NotebookLM as a university study assistant for BUS5001 Cloud Platforms and Analytics.

Features tested:
- source-grounded question answering
- study guide generation
- exam-style revision questions
- mind map
- interactive quiz
- Audio Overview

The evaluation considers:
- accuracy and relevance
- usefulness for study
- evidence quality
- limitations such as hallucination, over-reliance and source quality
